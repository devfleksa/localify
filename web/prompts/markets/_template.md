## Protect
What would be a cultural mistake or offence in this market: each bullet is a `must` finding for the scan.
3–8 short bullets, concrete and visible in an image (objects, gestures, symbols, numbers, colours).

## Language & formats
For text, price, cta and date cards: the copy language (the one language all localized copy uses) and tone, script
direction, currency and number format, date format, units, common short CTAs in that language, and how to keep new
text legible for the image model.

## Objects & food
Swaps for `object` cards, written "from → to", each with a visual description the image model can draw
(shape, colour, material, how it is served). Add any "always" rule for this market here.

## Places
Real, famous, recognisable places for `background` cards, grouped by scene type, each with visual cues:
### Billboard / skyline / big outdoor ad
### Shopping street / shop window / wall poster
### Bus stop / street-level transit
### Metro / station
### Roadside / landscape / coast
### Night

## Keep it real
How everyday places really look here (materials, light, wear, vehicles, street signs, people), so the edit looks
like a photo of the real spot and not a polished render.

## Never
Hard no's for edits in this market (things never to add or show), beyond the shared rules.
